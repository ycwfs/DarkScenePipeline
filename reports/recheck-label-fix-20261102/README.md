# 低置信度复核动作显示与保存修复（2026-11-02）

## 修复内容

`CandidateRecheck` 已确认的动作在事件层已经带有 `recheck.recovered=true`，但绘制层仍按
`.925` 再次过滤，导致画面显示“其他”。平台和 NVIDIA-Box 的 `render_people` 现在对已确认
的复核事件保留原动作标签和原始置信度；未确认候选、无效置信度和 `other` 仍按正常阈值显示为
“其他”。片段保存链路继续使用事件中的动作标签，因此显示、事件和文件名保持一致。

## 验证

- CPU 回归：89 项通过，包含复核状态机、绘制、片段、物体框和先验测试。
- `darkpipe-operator:0.3.0` 容器、RTX 3090、实际模型：输入 `input65.mp4`（65 秒，增强和
  超分关闭，用于隔离此次绘制修复），153 条事件中 1 条通过实际复核恢复为挥手，置信度
  `0.8771`；输出画面检查 1,915 次、保存侧画面检查 1,915 次，均按挥手绘制，均未降回其他。
- 实际运行保存 8 个动作片段和 1 个整段输出视频，全部完整解码；片段文件名与事件动作一致。
- 归档完整性：平台 tar 70 个文件、平台 zip 70 个文件、Box zip 100 个文件，压缩包测试无坏项，
  两个运行时均包含本修复。

验证细节在 `verification.json`，实际输入和输出在 `run2/`。该回放不是 RTSP 推流吞吐验收，
此次只针对动作类别显示、事件和保存的一致性。
