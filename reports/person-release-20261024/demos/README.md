# 真实分亮度、分人数演示

打开上级demos.html浏览13段完整视频；1240帧均为实际模型推理、完整H.264解码验证。
六档原图平均亮度：0–15、15–30、30–45、45–60、60–75、75+。低于30仅RGB；没有人工压暗。稳定2人样例并非每个档位都有，缺项见demo-selection.json。
回传多人负样本原图亮度未知，单独分组，候选框约4、8、13（峰值16）。候选框数不是人工真人计数。
这些来源属于训练集功能展示，不能当独立准确率测试；极暗首段有瞬时漏框、短捡物段有漏识，均保留真实输出，没有筛去失败帧。完整测试和局限见analysis-report.md。
模型、参数与部署包相同，不推理平滑、不使用物体先验。每人框下显示自己的动作；其他不显示低于阈值的具名动作。
