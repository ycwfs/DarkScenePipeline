## 识别结果与模型取舍

535个去重来源按417/60/58划分训练/验证/测试。参数网格包含7544组合，只用验证集选择，selection-lock.json锁定后统计测试。相同门30下，旧参数alpha.7/阈值.75→新参数.95/.91：验证宏F1 .7697→.8309，other误报6→4/162，正动作正确25→27/36；测试宏F1 .8477→.8646，other误报仍2/163，正动作正确33→37/51。

这是本批固定协议下的选择，仍有误报和漏识。历史初始化见过部分来源；组bootstrap的95%区间包含0，不能宣称显著或稳定的泛化提升。统计仅包含有可靠标签且形成窗口的人物，未检测出的人不计为正确。验证与测试的亮度/动作覆盖不均，尤其没有充分的30–75正动作测试，不能用亮度演示代替准确率结论。

人体YOLO26m使用暗场框＋剔除人形展品的亮场真人框微调；RTMO-s使用现场暗场辅助COCO17序列标签微调，推理不平滑；VideoMamba使用10-23逐人ROI现场＋两批线上other微调权重。本轮另训2507窗ST-GCN，20轮中验证选第13轮，但最终融合搜索仍选历史现场ST-GCN。Retinexformer保留公开NTIRE预训练：历史现场增强微调损害动作识别，因此未采用。不能把“现场模型”表述成五个模型都在本轮重新训练。

## 演示范围

13段/1240帧，六个原图亮度档：0–15、15–30、30–45、45–60、60–75、75+；包含单人、双人、三人及线上4/8/13候选框拥挤场景（峰值16）。每段均为真实来源，未人工压暗；已增强线上切片原图亮度未知，单独展示。每档并不都有稳定双人短片，缺项见demo-selection.json。人数是检测候选数，不是人工人数真值。

演示选自训练来源，按亮度/人数选取，不按识别成败筛选；全部H.264完整解码。极暗段有瞬时漏框，短捡物段有漏识，保留这些输出便于判断。每人框下只显示自己的最终动作；低于阈值显示其他，无全局底栏。尚未满1秒时序、照度门关闭或骨架不合格时不画骨架。

## 保存规则和证据

按人物ID＋动作分别保存完整画面，文件名含人物ID与会话/轨迹代次；不同人物或动作允许时间重叠。前后各2秒相对识别触发和最后同类事件，长动作15秒重叠续段。保存侧等待1.2秒对齐异步结果，并用触发事件重绘标签；直播不额外等待。真实动作起止未知、开头缓存不足、EOF、断流、强杀或过载时，不能保证每段有完整前后2秒；JSON明确记录context_complete和原因。

160项交付回归通过，包括两人同/不同动作、同人动作切换不切旧尾部、8人同时录制、长动作重叠续段、迟到结果、断流、停止、输出失败传播和前端有界顺序。原镜像真实挥手3离线160帧完整输出，保存一个连续159帧片段；Box原生测试挥手11产生不同人物动作的重叠片段。后者只验证真实模型事件的保存，不把预测类别当人工真值。

实时输入、RTMP推送及RTSP接收、MJPEG/FLV/HLS、输入暂停/断开、输出中继故障和客户端重连均有本机真实网络证据。具体帧率、时延、保存完整性和局限见stability-report.md；这是有限时长开发机回环测试，未连接实际平台摄像头、NFS/WebHDFS或实体NVIDIA Box，不承诺无限时长零故障。
