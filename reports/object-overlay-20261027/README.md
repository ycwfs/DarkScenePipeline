## 显示语义

物体类别使用英文短名：bottle瓶、cup杯、phone手机、camera相机、paper纸、item便携物、exhibit机器人/人形展品。青色框与人物动作的黄/绿框区分；非兼容物体也显示，包括被先验过滤为other的动作候选。物体标签末尾“~”表示局部光流跟随，分数仍来自原检测，并不是重新检测或新的动作分数。

源检测保存原图尺寸、源帧索引和时间，精确缩放到输出。晚到结果只有通过局部特征前后向校验才能跟随到当前画面；检测后最多0.6秒，无法对齐、当前原L低于门限、人物代次不符或断流时隐藏。新的空观测清除旧框。灰度缓存最多64帧/24MiB，按0.6秒淘汰；补绘事件缓存最多256条并清除过期历史。

离线完整视频增加1.2秒/最多64帧绘制缓冲，动作片段利用已有的1.2秒事件等待，把历史5采样帧的检出画回原采集帧；动作标签仍按原事件时间显示，**不会为了物体框提前显示动作**。实时输出不增加该缓冲，因此可能晚出现或少显示某次短暂检出。这是低延迟实时输出和事后录像的区别。

仅对达到动作阈值的喝水/捡物候选按需运行物体检测，不是全画面逐帧检测。没有框不等于现场没有物品。原L<35时仍跳过物体先验；没有降低物体阈值以制造更多框。

## 实际样本与发现

本轮真实运行原0.3.0镜像六模型：9段旧现场完整短片（8 train、1 val），3段多人原录像选段（25+30+30秒），共3037帧，生成12个自动动作片段；24个视频完整解码通过。选段用FFV1保存解码像素，未人为增亮。**没有重跑全部9段53.54分钟或全部407个旧来源**。单/双人身份沿用短期轨迹ID，多人候选峰值12/14/19，不视为独立人工计数。

- 单人喝水的瓶子、两人捡物的纸张能显示；挥手和低亮控制样本不额外触发物体模型。
- new-07、new-09仍存在手机/相机被当作瓶子的情况，分别保留一个喝水触发及相应片段。已知这些是误报，没有修改预测或挑掉失败结果。
- new-01含先前确认的真实喝水位置（原149.92秒附近），此次仍未检出兼容物体，触发被过滤，输出保留为other。
- old-08是历史other来源，仍产生捡物误报，并检出了周围物体。这再次说明“周围有物体”不足以证明发生交互。

这些是可视化与工程检查，不是重新训练、参数搜索或独立准确率测试。截取片段从头初始化跟踪，人物ID/窗口相位可能与此前整段回放不同。窗口触发数不能直接与历史全视频统计相减；短视频和EOF的片段上下文不足会如实标记。

## 最终包真实流核验

三RTX3090（物理1/4/5），最终TAR独立解包＋原镜像。85秒、2125源帧原速RTSP输入→RTMP主动推出→外部FFmpeg录制；另有75秒测试预热及收尾，接收录像保留。主段实际处理1512帧，按实时最新帧策略跳过部分源帧，不能称逐帧无损；没有画帧号黑白条。

82次健康检查均HTTP200/ok，输入重连/推流重启/HLS重启均0；196事件，正常SIGTERM退出0。12个动作片段、11个上下文完整，写入失败/强制释放/未完成/录制丢帧/弃段均0。22个流式输出、HTTP查看器和片段视频完整解码通过。真实输出24帧显示物体框，验证了异步结果的当前帧跟随路径。

处理FPS中位17.42、最低14.96，采集到处理输出延迟P95 222.3ms；这些是当时共享开发机的有限测量，不是新增绘制耗时的受控前后对照，也不是实体平台或无限流性能承诺。离线/Box另检24+2视频，本轮合计48个输出文件完整解码。
