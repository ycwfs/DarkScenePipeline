# 旧现场逐人动作＋单帧物体先验评估 · 2026-10-26

固定采用用户选择的现场七类 YOLO26m、720 Retinexformer 增强图裁剪。动作阈值0.85、RGB权重0.95、原图门30、物体阈值0.35；未训练、未重新选参数。

主要范围为407段旧现场原视频（real-actiondata-all 390段＋real-actiondata 17段），另128段历史线上回传仅作附录。原现场39304帧；336段产生2089个逐人窗口，已标注1564，未知525。71段没有可评估窗口，不能计为正确；这些视频的文件级标签分布为{'other': 55, 'drink': 2, 'wave': 3, 'chase': 8, 'pick_up': 3}。窗口时刻候选人数分布：{2: 344, 1: 1651, 3: 94}，检测数量不是人工人数真值。

## 方法与可复核证据

本次是**冻结逐人窗口回放＋新物体推理**。五个原模型SHA256与生产模型和历史缓存全部相同；全部535来源哈希、缓存和逐人32帧索引已核验。RGB／骨架概率复用原推理，调用当前生产fuse_person按0.95/0.85重算。人体框、姿态、跟踪同样复用，以控制加入先验前后的变量。并非重新执行全量实时PersonEngine。

新推理实际解码候选窗口的原视频，原图缩至长边720，再整帧Retinexformer增强；每窗从32帧选5个均匀位置，对30%外扩的人物区域及可信的手/头/脚局部区域裁剪、640letterbox检测。共新增强1128帧，检测2225张独立裁剪。裁剪坐标按floor/ceil准确回映，跨区域同类去重。至少一帧同人区域检出瓶/杯支持喝水；检出瓶/杯/手机/相机/纸/便携物支持捡物。

原窗口亮度<30或未知则不启用先验；采样帧也执行亮度门；人物重叠IoU>0.4弃权；没有有效亮帧观测则保持原结果。有有效观测但没有兼容物体才变为other。没有新增手机/展品单帧否决规则，物体出现也不证明正在互动。五帧抽样不保证捕获整个动作中的短暂物体。

正式平台包暂未接入该逐人裁剪候选。本轮没有修改包或镜像，也没有进行实时速度/稳定性验收。

## 限制和结论边界

这批现场数据主要来自训练场景，train用于看拟合情况；val/test按旧source group保留，但历史初始化已经见过部分来源，测试也曾反复检查，因此不能宣称独立新场景泛化。525个未可靠逐人标注的现场窗口全部排除精度计算，71段无可用窗口不作为识别成功。固定来源辅助标注和人物关联可能有误差；真实动作片段完整召回需独立逐帧真值。

图1同时显示真动作保留和类别误报，图2区分训练/验证/测试的收益、损失及未知标签。先验确实能阻止部分缺少物体证据的动作触发，但旧现场真实互动动作也可能因物体小、遮挡或检测遗漏被过滤。不能把过滤量或总体accuracy上升单独解释为效果提升。
