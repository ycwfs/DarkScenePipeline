两模型从原正式权重初始化，保持上一轮的学习率、旧数据蒸馏、类别／来源加权采样、seed29和更新步数。RGB6轮×700个全局batch8更新、四卡0/1/4/5；ST-GCN20轮×59个batch64更新。GPU2/3的外部任务不动。新other的采样概率仍为1.28%，全部other为10.26%；原始窗口占比不等于训练批次占比。

四参数固定为alpha .972／原图亮度门35／动作.925／物体.581，挥手3帧、跑动.35人体框高度/秒。只按旧canonical验证集198窗选择147种权重组合，不调阈值。除允许保留初始化权重的选定组合外，同时保存旧验证集选出的“两分支都已微调”组合和预定末轮组合，避免把保留原RGB误写成新RGB的效果。
