# 暗场人体框：视觉标注可行性核对

结论：部分检测器漏检的暗场帧仍能通过视觉核对定位人体，可以制作框标注草稿；极暗且边界不可辨认的帧不能承诺准确标注。
本次由Codex查看原图、仅调整显示的Gamma图、既有Retinexformer增强预览与相邻帧后放置候选框。
没有独立人员复核或人体框真值，不能把“已画框”称为经过精度验证的训练标签。

每个关键帧均查看前后各1帧，共27个不同视频帧。没有给全视频逐帧标框，没有运行新的检测模型，
也没有复制模型预测框。已有模型预览仅辅助查看，与本次直接标框不是独立的盲法对照。
原帧显示调整只改变亮度映射，不补画人体、不使用生成式修复。

坐标为原始1920×1080像素，`bbox_xyxy`采用左上包含、右下不包含的约定；附带`bbox_xywh`和归一化YOLO坐标。
框按当前可见人物范围放置，包含可辨认手臂，不外推图像外身体，不包含地面阴影；细边缘仍有人工判断误差。
文件名中的动作没有作为动作真值，`action_label=null`。

所有记录均为`pending_independent_review`且`include_in_training=false`。
3个不确定帧使用`uncertain_do_not_use_as_negative`，**无框表示未能可靠标注，不能导出成“无人”的空标签负样本**。
本次只检查可见目标，不声明已对全画面所有可能遮挡的人完成穷尽标注。
原数据、训练拆分、模型、算子和镜像均未修改。此处离线视觉判断不能等同于实时检测模型已能识别暗场人体。
