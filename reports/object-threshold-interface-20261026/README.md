# 物体检测阈值与参数入口 · 2026-10-26

新裁剪物体实验支持阈值为0.35；保守规则的手机/相机否决门为0.65，展品否决门为0.85。当前正式逐人算子未启用物体先验。

新增源码参数`--object_min_conf 0.35`，平台Float输入、容器传参、离线/实时PipelineConfig、配置日志和历史整帧检测器贯通；范围为有限0–1。仅person_mode=false且fuse_mode=max_prior生效；当前逐人模式输出object_prior=off。共享ONNX包装器使用实例阈值，人体模型继续独立筛选（包装器预筛0.25，person_boxes最终0.35）。

人体权重`yolo26m_person_20261024.onnx`与物体实验权重`yolo26m_objects_candidate.onnx`同属YOLO26m结构，但训练权重及类别不同。旧整帧PriorGate使用的是COCO-80 `yolo26m_detect.onnx`，不能直接换成七类候选权重。

七类训练框（含辅助视图）来自已审核的历史现场视频/回传ROI：瓶115、杯0、手机44、相机3、纸64、其他可移动小物2、机器人/展品23。相机主要为三脚架相机，缺少手持相机靠脸的覆盖。来源、标注局限和分割见[原实验报告](../object-prior-finetune-20261025/analysis-report.md)。
