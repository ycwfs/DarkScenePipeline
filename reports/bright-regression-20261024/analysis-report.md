# 亮场性能保持分析

主要问题：固定暗场验证集选出的微调权重，在保持部署预处理和阈值时，是否保留亮场人体检测和姿态能力？四组合对照将检测器改变和姿态模型改变分开。

**最强证据是否定检测器的全场景替换。** 明确非真人的人形展品，在9段955帧中被检测的比例从4.08%变成98.85%，增加94.76个百分点；只换检测器已复现组合后的假骨架增长。两版RTMO都对展品输出姿态框955帧，故新增显示并不是姿态微调独自造成。

41帧47个助手辅助人物框，IoU≥0.5匹配由45降至41，减少4个匹配；IoU≥0.3时由46降至41，减少5个匹配。两种尺度都支持远处真人检测退化。IoU阈值变化反映辅助边界不确定性，不能用单个阈值宣称精确召回率。

单换姿态时，匹配真人且≥10点的实例39→41（47个实例中的比例增加4.26个百分点）；原检测框上未匹配骨架数仍为0，展品全序列误显示仍为39帧。本次支持“被核对样本的骨架覆盖略改善”，不支持“亮场关节点精度全面保持”。未匹配姿态框也不能全部当作假人，部分是人体框范围差异。

检测耗时中位16.92→17.05ms，姿态10.31→9.95ms。两者保持同量级，检测效果比运行速度更影响当前换装决定。

数据只有同一现场的一批41段测试原片，实际L为102.23–121.56；没有75–102过渡亮度、异地家庭环境或人工关节点真值。一次训练线、一次评估进程不支持总体非劣效检验。不给出虚假的显著性或“无退化”证明，详见 [统计附录](stats-appendix.md)。

决策：保留原检测器；“原检测＋微调姿态”作为下一步单独核验候选。此次不换装、不再训练；推理平滑按用户要求停用。
